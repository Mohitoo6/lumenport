**Question:** do the AI ministers argue about the actual problem from the game’s real data, or do they just produce plausible-sounding text?

**Method.** Three independent kinds of evidence:
1. *Deterministic checks* (code, no AI): every number a minister says is looked up in the exact prompt that minister received; option letters must exist; Hindi meetings must be in Devanagari; length rules.
2. *Behavioural tests*: a controlled experiment where one fact is changed and everything else is held fixed, and a meeting under the mayor’s explicit constraints. If the model were only generating plausible text, positions would not move with the data.
3. *LLM-as-judge*: a different model scores every statement 1–5 for grounding, relevance, staying in role and reasoning, with the same evidence the ministers had. The judge is itself tested with planted bad statements.

## Limits of this evaluation

- One scripted town and one run per scenario (two per counterfactual variant): free-tier rate limits make large samples slow. Results show behaviour, not a statistically tight rate.
- The number check is conservative: it flags arithmetic it cannot reproduce (for example a percentage computed by the minister), so every flag is listed for a human to read.
- The judge is a language model too; section 4 measures whether it catches known-bad statements, but it can still miss subtler errors.
- Whether a recommendation is the *best* policy is a value judgement; these tests check that it is grounded, consistent and responsive to data and instructions.
